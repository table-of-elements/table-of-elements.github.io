# Planning Poker

Planning Poker ist eine Technik zur Schätzung des Arbeitsaufwands in agilen Projekten. Teammitglieder verwenden Karten mit Zahlenwerten, um die Komplexität von User Stories oder Aufgaben zu bewerten.
